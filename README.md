# CTC Salary Calculator India (FY 2026–27)

A modern, responsive CTC (Cost to Company) Salary Calculator for India for Financial Year 2026–27.

## Features

- **Accurate In-Hand Salary Calculation:** Computes Monthly In-Hand and Annual Take-Home salary based on Indian tax rules for FY 2026–27.
- **Tax Regimes:** Supports both **New Tax Regime** and **Old Tax Regime**.
- **Comprehensive Salary Components:**
  - Basic Salary, HRA, Special Allowance, Variable Pay / Bonus
  - Employer & Employee Provident Fund (EPF) with wage ceiling options
  - Gratuity provisions & Professional Tax
- **Professional Reports:**
  - **Download PDF:** Clean, single-page salary report with Indian number formatting (`Rs 1,20,00,000`), proper margins, and official watermark.
  - **Download Excel / CSV:** Detailed salary breakdown export.
  - Built-in 15-second countdown with preserved data snapshots.
- **Responsive UI:** Clean, modern interface designed for desktop and mobile devices.

## Usage

Simply open `index.html` in any modern web browser or deploy directly to GitHub Pages.
